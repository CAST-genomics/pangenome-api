PangenomeAPI · interaction reference

Click to Tube Map

One right-click in the 3D graph, and the route it travels: two repositories, three processes, five file formats, and one collector that every drawn shape passes through.

Drawn against the pipeline as it stands after the seqtubemap refactor — the invisible browser deleted, the geometry collected as numbers, the band payload served as an additive second encoding. 2 September 2026. Rendered at claude.ai/code/artifact/ca74cc4a. Vocabulary is CONTEXT.md: the coarse thing clicked in 3D is a node, the fine vertices inside the map are segments, a haplotype’s route is a strand, and one strand crossing one x-interval is a band.

The whole routeWhat happens between the click and the picture

1The click is a gate, not a request

The click never reaches the network directly. It reaches an eligibility check, and the check is not optional: the API answers an unknown minigraphnode with 200 and a plausible-looking map of different data. There is no error to detect at request time, so an ineligible node has to be stopped in the client or not at all.

Why disabled, not hiddenFifteen of the forty-five nodes in cici.json have no GRCh38 placement. A menu item that vanishes for a third of the graph is indistinguishable from a mis-click, so the item stays and carries its reason: Sequence Tube Map — no GRCh38 placement.

What is fixed in the URL, and why

A flag, never a fallback. The obvious design — ask for bands, fall back to the document — is a trap on this API specifically. Its failures arrive at 33–100 s with no CORS headers, indistinguishable in the browser from a network error, against a patience of 90 s. A fallback would spend up to ninety seconds before the second request began, on exactly the large nodes the whole effort exists for. So the viewer never probes and never learns what the server supports; it is told, by one constant, and that constant was flipped on 2 September 2026.

2Region to vg JSON

The handler is synchronous on purpose: it blocks, so it belongs in FastAPI’s threadpool rather than on the event loop. Every stage below is wrapped in a timer, and one [stage-timing] line per request carries the breakdown, so latency can be attributed with a grep.

A cache hit is a content checkThe W lines are written last, after every S and L line, so an extraction that died partway leaves a structurally valid GFA describing a graph with no paths in it — which every downstream stage then fails on, each for a reason further from the cause. Checking for walks, plus an atomic rename, turns that into one retry.
One tabix handle per threadA TabixFile is one htslib handle with one seek position, and fetch returns a lazy iterator — held open per S line, for minutes on a large region. Two requests really do overlap on the threadpool, and sharing one handle interleaved the seeks and left it broken for the life of the process.

3vg JSON to band data

One Node process, and no browser in it. The layout used to bind its numbers to elements in an emulated document, which was 93.7% of the render’s retained memory and existed only so the result could be serialized to text and parsed straight back into numbers by the client. Now every draw function collects what it was about to draw.

The one sequencing constraint leftThe layout reads its config out of a global at module scope and throws if it is not there. So the config is installed first and tubemap.js is imported dynamically — once per process, not per render, because the module carries the layout’s state and create() resets it before it draws.

A fixed sequence of passes over the segments and strands, ending in draw calls whose order is paint order, which is document order, which is the order the emitter writes them in.

A band is six numbers and a strand id

Those six are x0, y0 and x1, y1, the two ends of the band’s upper edge, and controlTop, controlBottom, the control abscissae of the two cubics. Six is enough only because every band is exactly 15 units thick — a constant measured across 127,101 strand paths, and the reason the lower edge does not have to be sent at all.

Collected shapeKindWhat it is
rectBandrectthe degenerate band — level, so any control abscissa reproduces it
curveBandcurvethe same six values; the kind says only which element the document writes
cornerShapecornera quarter turn built from quadratics — outside the six-value grammar
verticalConnectorconnectoras tall as the reversal is deep, which is not the band thickness and is not meant to be
segmentBox—five numbers: left, top, right, bottom, radius
ruler, sequence labelsoverlayan element name and its attributes in order; no production response contains one

Two invariants are checked here, where the layout that produced them is still in scope, rather than downstream where it is not. A band drawn off the grammar throws in the collector rather than reaching a client that would refuse the whole response. And strand ids are asserted dense: hidden strands are spliced out after ids are assigned, so a hole is possible, and pgb rejects an entire map whose ids do not run from zero upward with no gaps.

4Two sinks, one collector

Everything above the collector computes numbers; everything below it encodes them. The document and the payload cannot disagree about the picture, because there is only one picture: the band data is canonical, and the document is a rendering of it.

Reversals ride in the header rather than the body: a corner is quadratics and a connector is not band-thick, so neither fits the six-value grammar. Each carries the position it occupied in the draw order, because paint order is document order.

uint32 LEbyte length of the header

Columnar, not one record per band. Interleaved, a band is a 26-byte stride, and a Float32Array cannot view a buffer at an offset that is not a multiple of four — so a client would have to copy the fields apart one at a time with a DataView, which is exactly the parse step this format exists to delete. Split into columns, each column is a single view over the bytes that arrived.

5Bytes back to a picture

The encoding is not passed inIt is the shape of what arrived. The fetch reads the body as text or as bytes according to the flag the host set, so a string is a document and a byte array is a payload, and there is no third state in which the two could disagree about which one this is.

6What the stages cost

All of that is with the format unchanged. The format is where the eight-thousand-base response goes from roughly 10 MB to 1.10 MB.

7Invariants this route rests on

  • The band data is canonical; the document is a rendering of itrender.mjs — one collector, two sinks
  • A cache hit is a subgraph with walks, not a file at a pathsubgraph_has_walks, main.py
  • A half-written subgraph never becomes a cache entryGenerateWalksMC — partial file, then os.replace
  • One tabix handle per thread, and that is load-bearingWalkDerivative._per_thread
